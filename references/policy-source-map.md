# 政策与红头文件信源地图（policy-source-map）

> 找政府/事业单位政策文件、红头文件时读本文件。核心原则：**搜索引擎只用于"发现线索"；要进评估报告或具法律效力的文本，必须回官方库/专业库取原文，并确认时效（现行有效/修订/废止）。**

## 1. 红头文件的特点与定位钥匙

- 发布集中在 gov.cn 及各主管部门官网；形态有 HTML、PDF 附件、扫描件图片（扫描件需核对 OCR）。
- **发文字号是精确定位钥匙**，如"国办发〔2016〕80 号""×府办发〔2026〕15 号"；检索时保留中文六角括号〔〕。
- 五级层级：国家 → 省 → 市 → 区县 → 乡镇。评估最常用**市级**，**区县级最偏门**、搜索引擎最难收录。
- 历史归档难：基层网站常改版、旧链接易 404；多年前文件优先专业库，或网站"政策文件库 / 政府公报 / 政府信息公开年报"栏目。

## 2. 免费官方权威库（T1，优先）

中央级：
- **国家法律法规数据库**（全国人大；法律/行政法规/监察法规/司法解释/地方性法规，免费权威、标注时效）：https://flk.npc.gov.cn
- **国务院政策文件库**（国务院文件检索）：https://sousuo.www.gov.cn/zcwjk/
- **国家规章库**（部门规章、地方政府规章现行有效文本）：从中国政府网"法律法规 → 国家规章库"入口进入。
- **国务院公报**：公报刊登文本为标准文本。
- **住建部**：https://www.mohurd.gov.cn （房地产调控、住房保障、建筑市场、房屋征收补偿）。

行业导航：
- **中房网政策法规库**（中国房地产业协会，汇总中央+地方房地产政策，适合先纵览再回源）：https://www.fangchan.com/policy

地方级：
- 各级政府"政策文件库 / 行政规范性文件库 / 政府公报"；省住建厅、省自然资源厅；市住建局、市自然资源和规划局、市住房公积金中心；区县政府政策文件栏目。
- 站内路径通常是"信息公开 → 政策法规/规范性文件"，按文号或标题检索，注意筛"现行有效"。

## 3. 专业数据库（付费/机构授权）

- **北大法宝 PKULaw**：法律/行政法规/部门规章/地方性法规/司法解释/案例较全，有**修订沿革与现行有效/废止标注**、法条关联；不收录党委系统文件。**本环境优先调用 `pkulaw-legal-data` 技能检索并核时效**；技能未覆盖或连接器不可用时，再考虑机构订阅。
- **人民数据库**：党政时政综合，强项是**党委文件（中发/中办发）、政策解读、领导讲话、人民日报全文**；法规不如法宝全、无时效沿革，地方主要到省级。以机构 IP 授权为主，个人多通过高校/公共图书馆访问。
- **分工**：要"现行有效法律依据" → 法宝；要"党委文件/政策背景解读" → 人民数据库；区县级执行细则两者都可能缺，回当级政府官网。
- 收录规模、价格随时间变化且多为机构口径，引用前以官方/机构当时页面为准，不在技能里写死。

## 4. 五级分层找法

| 层级 | 主要站点 | 典型文件 |
| --- | --- | --- |
| 中央/国家 | 全国人大、国务院、住建部、自然资源部 | 法律、条例、全国性调控政策 |
| 省 | 省住建厅、省自然资源厅 | 省规范性文件、省级补偿/调控细则 |
| **市（评估最关键）** | 市住建局/房产局、市自规局、市公积金中心 | 限购限售、公积金、预售、基准地价、出让与规划条件 |
| 区县（最偏门） | 区县政府政策文件库、区县住建分局 | 征地补偿标准、片区执行细则 |
| 乡镇/街道 | 街道办公开栏 | 个别公告，常需依申请公开 |

## 5. 标准检索动作

1. 先用内置搜索（中文政策语义更准）以"关键词 + 文号"定位线索；海外/英文政策才开代理或走海外搜索 API。
2. 用文号/精确标题到第 2、4 节的官方库取原文，优先 PDF 标准文本。
3. **核时效**：现行有效 / 已修订（取最新版并留沿革）/ 已废止（不得作为评估依据）；记录 status 与核对日期。
4. 留存原文，记录 sourceUrl、sourceName、sourceTier=T1、accessStatus、文号、发文机关、效力层级；打不开或遇付费墙如实标 accessStatus，不据摘要下强结论。
5. 偏门地方旧文件找不到时，走政府信息公开"依申请公开"或专业库/图书馆，不在搜索引擎上空耗。

## 6. 房地产评估常用政策对照

| 评估需要 | 主要来源 |
| --- | --- |
| 基准地价/标定地价、出让与规划条件 | 市自然资源和规划局、中国土地市场网 |
| 限购限售、预售、网签 | 市住建局/房产局 |
| 贷款额度、首付、公积金 | 市住房公积金管理中心 |
| 征地拆迁补偿标准 | 省/区县政府、住建（征收）部门 |
| 交易/持有税费 | 税务/财政部门、人大法规 |
| 造价/重置价格 | 地方造价站、造价管理协会 |
| 判断文件是否现行有效 | 国家法律法规数据库 / 北大法宝（pkulaw 技能） |
